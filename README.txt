# Alvorada Mística — site inicial

Este é um site estático pronto para publicação.

## Estrutura
- `index.html` — página principal
- `style.css` — visual responsivo
- `assets/logo-alvorada-mistica.png` — logo
- `assets/feito-com-carinho.png` — selo "Feito com Carinho"

## Personalização
Edite o `index.html` para trocar produtos, textos, links e contatos.

## Domínio
O endereço solicitado `alvorada.mistica.com.br` é um subdomínio de `mistica.com.br`.
Para ele funcionar, quem administra `mistica.com.br` precisa criar o subdomínio no DNS e apontá-lo para a hospedagem do site.
Se você ainda não possui `mistica.com.br`, uma alternativa é registrar um domínio próprio como `alvoradamistica.com.br` (se estiver disponível).

Importante: o arquivo do site não registra o domínio nem configura DNS automaticamente.
